# React Design Library Agent

Clones a GitHub repo of React components, renders every exported component (and its prop variants) in headless Chromium, screenshots it, and writes a browsable design library.

```
npm install
npm run setup          # installs Chromium
npm run build:swiss    # demo against detonnate/reactSwissComponents
node src/cli.mjs <github-url|path>
```

Output (always `output/<repo-name>/`, one location for every run): `CATALOGUE.md` and `CATALOGUE.html` (every screenshot compiled into one catalogue, both generated by default; pick whichever format you prefer), `index.html` gallery with search, `components/<Name>.html|.md` (screenshots, JSX usage, rendered HTML, props table), `html/` standalone HTML snippets for mockups, `screenshots/`, `manifest.json`.

**Example output:** a full run against https://github.com/detonnate/reactSwissComponents is committed in [`output/reactSwissComponents`](output/reactSwissComponents). Open `output/reactSwissComponents/index.html`, `output/reactSwissComponents/CATALOGUE.html`, or read [`CATALOGUE.md`](output/reactSwissComponents/CATALOGUE.md).

Props and variants are inferred from TypeScript types. For components needing real data, pass `--examples file.jsx` (see `examples/swiss.examples.jsx`; `@repo/` aliases the target repo). Other flags: `--dirs`, `--css`, `--only`, `--exclude`, `--width`, `--branch`, `--skip-install`.

The Copilot custom agent is in `.github/agents/design-library.agent.md`; a manual GitHub Actions workflow is in `.github/workflows/design-library.yml`.
